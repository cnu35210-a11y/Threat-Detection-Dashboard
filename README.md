# Threat-Detection-Dashboard
Aplicacion de escritorio en Java 17 + JavaFX que simula un mini SIEM/SOC: ingesta logs (JSON/CSV), los correlaciona contra un motor de reglas estilo Sigma, calcula severidad, mapea cada alerta a MITRE ATT&amp;CK, y permite simular una respuesta automatizada (Mini-SOAR) de contencion de red.
